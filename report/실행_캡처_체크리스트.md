## Part 1. 스키마 분석 및 트랜잭션 시뮬레이션

대부분 캡처 완료. **남은 항목: 고립성 2세션 검증 (Figure 1-57)**

- [ ] **고립성(Isolation) 2세션 캡처**
  - 세션 1: 변경 후 COMMIT하지 않음
    ```sql
    -- 세션 1
    UPDATE BO.PRODUCTS SET PRODUCT_PRICE = 19000 WHERE PRODUCT_ID = 20001;
    -- COMMIT 하지 말 것
    ```
  - 세션 2: 기존 값이 보이는지 조회
    ```sql
    -- 세션 2 (다른 접속)
    SELECT PRODUCT_ID, PRODUCT_PRICE FROM BO.PRODUCTS WHERE PRODUCT_ID = 20001;  -- 기존 값이어야 함
    ```
  - 세션 1: COMMIT → 세션 2 재조회(변경값 확인)
    ```sql
    -- 세션 1
    COMMIT;
    -- 세션 2
    SELECT PRODUCT_ID, PRODUCT_PRICE FROM BO.PRODUCTS WHERE PRODUCT_ID = 20001;  -- 변경값
    ```
  - 정리(T7 기준값 복구)
    ```sql
    UPDATE BO.PRODUCTS SET PRODUCT_PRICE = 18000 WHERE PRODUCT_ID = 20001;
    COMMIT;
    ```

### Case 4A — CUST_CONTACTS 삭제 → Flashback Table (SCN)
- [ ] **Figure 3-4 삭제 전/후/복구 (219,995 → 0 → 219,995)**
    ```sql
    ALTER TABLE BO.CUST_CONTACTS ENABLE ROW MOVEMENT;
    COLUMN BEFORE_SCN NEW_VALUE V_BEFORE_SCN NOPRINT
    SELECT DBMS_FLASHBACK.GET_SYSTEM_CHANGE_NUMBER BEFORE_SCN FROM DUAL;
    SELECT COUNT(*) BEFORE_CNT FROM BO.CUST_CONTACTS;
    DELETE FROM BO.CUST_CONTACTS; COMMIT;
    SELECT COUNT(*) AFTER_DELETE FROM BO.CUST_CONTACTS;   -- 0
    FLASHBACK TABLE BO.CUST_CONTACTS TO SCN &V_BEFORE_SCN;
    SELECT COUNT(*) AFTER_FLASHBACK FROM BO.CUST_CONTACTS; -- 219,995
    ALTER TABLE BO.CUST_CONTACTS DISABLE ROW MOVEMENT;
    ```

## Part 5. 배치 프로그램 수행시간 측정 및 성능 개선

- [ ] **Figure 5-2 1,000건 실행 이력 (RUN_ID 1·3·21)**

           TO_CHAR(ELAPSED_SEC,'FM9999990.000') ELAPSED_SEC,
           TO_CHAR(ELAPSED_SEC/TARGET_CNT*1000,'FM9999990.0000') MS_PER_ORDER, STATUS
    FROM BATCH_RUN_LOG WHERE RUN_ID IN (1,3,21) ORDER BY RUN_ID;
    ```
- [ ] **Figure 5-3 OPTIMIZED 100,000건 수행 결과 (RUN_ID 4)**

           TO_CHAR(ELAPSED_SEC,'FM9999990.000') ELAPSED_SEC, STATUS

    ```
- [ ] **Figure 5-4 100,000건 정합성 (집계 + 주문별 + FK)**
    ```sql
    DEFINE RUN_ID = 4;
    WITH R AS (SELECT START_ORDER_ID S, END_ORDER_ID E FROM BATCH_RUN_LOG WHERE RUN_ID=&RUN_ID)
    SELECT 'ORDERS' T, COUNT(*) CNT FROM ORDERS O,R WHERE O.ORDER_ID BETWEEN R.S AND R.E
    UNION ALL SELECT 'ORDER_ITEMS', COUNT(*) FROM ORDER_ITEMS I,R WHERE I.ORDER_ID BETWEEN R.S AND R.E
    UNION ALL SELECT 'SHIPMENTS', COUNT(*) FROM SHIPMENTS S,R WHERE S.ORDER_ID BETWEEN R.S AND R.E;
    -- 주문별 구성 오류 0건
    WITH R AS (SELECT START_ORDER_ID S, END_ORDER_ID E FROM BATCH_RUN_LOG WHERE RUN_ID=&RUN_ID)
    SELECT COUNT(*) INVALID_ORDER_CNT FROM ORDERS O,R
    WHERE O.ORDER_ID BETWEEN R.S AND R.E
      AND ((SELECT COUNT(*) FROM ORDER_ITEMS OI WHERE OI.ORDER_ID=O.ORDER_ID) NOT BETWEEN 1 AND 3
        OR (SELECT COUNT(*) FROM SHIPMENTS S WHERE S.ORDER_ID=O.ORDER_ID) <> 1);
    UNDEFINE RUN_ID;
    ```
